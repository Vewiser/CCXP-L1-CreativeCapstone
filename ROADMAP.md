# Roadmap

## Cycle 1 — one complete proof

- [ ] Select one real audience and problem.
- [ ] Finish the creative brief and offer canvas.
- [ ] Build a low-cost prototype within seven days.
- [ ] Run three real feedback sessions.
- [ ] Publish one evidence-based case study.

## Cycle 2 — repeatability

- [ ] Convert successful steps into checklists and templates.
- [ ] Create an intake-to-delivery workflow.
- [ ] Define quality gates for voice, visual consistency, and claims.
- [ ] Price a fixed-scope pilot offer.

## Cycle 3 — portfolio system

- [ ] Add VisionBuilt, VisionFlow, VisionRoots, and VisionWell examples.
- [ ] Track time, cost, outcomes, and reusable assets.
- [ ] Review tools quarterly and remove anything that adds complexity without leverage.
